現場人員怎麼用？

  1. 更新輸入檔：每日改 shift-handoff-input.md；庫存與設備表可從 WMS／設備主檔匯出覆蓋 CSV。
  2. 等排程或手動測試：到 AI 控制台 的 Cron 區查看下次執行；管理員可用 openclaw cron run <job-id> 立即試跑。
  3. 取結果：完成後到 automation/outputs/ 開啟當日 md 檔，審閱後再貼回 MES／ERP。

與網頁工具的差別：上方 25 項工具在瀏覽器內產生草案；這三項由 Gateway 背景執行 OpenClaw Agent，需 Gateway 持續運行。

推播（選用）：預設只寫檔、不發 LINE／Discord。若要推播，請在控制台編輯 Cron 任務的 Delivery 設定。

重新安裝排程：工作區執行 ./scripts/setup-manufacturing-cron.sh（詳見 automation/README.md）。
