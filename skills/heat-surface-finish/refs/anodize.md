## 鋁陽極處理 (Anodizing)

### 三大主流類型 (MIL-A-8625)

| Type | 名稱 | 電解液 | 膜厚 | 硬度 | 顏色 | 用途 |
|---|---|---|---|---|---|---|
| **I / IB** | 鉻酸陽極 CAA | CrO3 + H2O | 0.5-7.5µm | — | 灰 (不可染) | 航太 — 不影響疲勞 |
| **IC** | 硼酸-硫酸 BSAA | H2SO4 + H3BO3 | 1.8-7.5µm | — | 灰 | Type I 環保替代 |
| **II** | 硫酸陽極 SAA | H2SO4 15-20% | 5-25µm | HV 200-400 | 可染各色 | 一般外觀件、3C |
| **III** | 硬陽極 Hard | H2SO4 + 添加劑, 0°C | 25-150µm | HV 400-600 | 灰 / 黑 (染色受限) | 耐磨、氣動液壓缸、模具 |

### 製程參數

```
Type II (一般陽極)
  電解液:  15-20% H2SO4, 18-22°C
  電壓:    14-22 V (DC)
  電流密度: 1.0-1.6 A/dm²
  時間:    25-60 min (要 10µm 約 30 min)
  
Type III (硬陽極)
  電解液:  10-15% H2SO4 + 添加劑, -5 to +5°C (重點!)
  電壓:    20-100 V (隨膜厚上升)
  電流密度: 2-4 A/dm²
  時間:    依膜厚 (50µm 約 60 min)
  
染色 (Dyeing)
  Type II 出槽後 → 水洗 → 染色 60°C × 5-20 min → 封孔
  染料: 有機 (色彩鮮) / 無機 (耐光好) / 電解染 (黑 → 鈦/鎢鹽)
  
封孔 (Sealing)
  熱水封孔:        DI 水 ≥ 96°C × 30 min   (傳統,孔徑大)
  鎳鹽封孔:        Ni-acetate 90-95°C × 15 min (耐蝕最佳)
  冷封孔:          Ni-F 25-30°C × 10 min (節能,但需老化)
  測試: 染斑試驗 ISO 2143
```

## 鋁合金可陽極性

```
合金系       可陽極性    說明
─────────────────────────────────────────
1xxx (純鋁)   ★★★★★   膜均勻,但軟,染色佳
3xxx (Al-Mn)  ★★★★    略灰、染色尚可
5xxx (Al-Mg)  ★★★★★   3C 主流 (5052/5086) 染色佳
6xxx (Al-Mg-Si) ★★★★    型材主流 (6061/6063) 染色好,硬陽極佳
7xxx (Al-Zn)  ★★★      染色易發暗,硬陽極注意裂紋
2xxx (Al-Cu)  ★★       Cu 高 → 膜黑,需 IC/CAA
壓鑄 ADC12    ★          Si 高 → 膜灰黑、不均勻 (改噴砂遮)
```

## 缺陷對應

| 缺陷 | 原因 | 對策 |
|---|---|---|
| 膜薄 / 軟 | 槽溫高 / 電流不足 / 時間短 | 降溫、增電流、延時 |
| 燒焦 (Burn) | 局部電流密度過大、接觸不良 | 改善掛具、降電流 |
| 點蝕 / 麻點 | 槽液 Cl⁻ 污染 (> 50ppm) | 換液 / 沉澱去 Cl |
| 色差 | 槽溫不均、攪拌差、染料失衡 | 加循環、控槽溫 ±1°C |
| 白斑 (封孔斑) | 封孔水質差 / 染料殘留 | DI 水、染後充分水洗 |
| 龜裂 (硬陽極) | 升溫過快 / 截面厚薄差 | 緩慢升電壓 / 預熱 |

## 規範

- MIL-A-8625F — 美軍規,Type I/II/III 經典依據
- ISO 7599 — 工業陽極
- ASTM B580 — Method A-G (對應 MIL Type)
- AAMA 611 — 建築陽極鋁 (高耐久 Class I/II)
- JIS H 8601 — 日規
- 染色耐光: ISO 2135 (Light fastness test)
- 封孔測試: ISO 3210 (酸溶失重) / ISO 2143 (染斑)
