## 不銹鋼鈍化 / 酸洗 / 電解拋光

### 鈍化 (Passivation)

目的: 去除游離鐵 (free iron) + 富鉻表層生成緻密 Cr2O3 鈍化膜 → 提升耐蝕。

| 製程 | 溶液 | 條件 | 規範 | 適用 |
|---|---|---|---|---|
| 硝酸鈍化 (傳統) | HNO3 20-50% + Na2Cr2O7 2-6% | 50°C × 30 min | AMS 2700 Method 1 / ASTM A967 | 通用,效果穩 |
| 檸檬酸鈍化 (環保) | 檸檬酸 4-10% | 60-70°C × 20-40 min | AMS 2700 Method 2 / ASTM A967 | ROHS/環保場景 |
| 草酸電解鈍化 | 草酸 10% + DC | 5-10 V × 5 min | — | 焊縫局部 |

### 酸洗 (Pickling) vs. 鈍化

```
酸洗   = 強酸 (HNO3 + HF) 去 鐵鏽 + 氧化皮 + 焊接彩色
鈍化   = 中強酸 (HNO3 / 檸檬酸) 去 游離鐵 + 重建鈍化膜
電解拋光 = 強酸 + 電流 → 鏡面 + 鈍化 (Ra < 0.1 達成)

順序: 加工/焊接 → 酸洗 → 水洗 → 鈍化 → 水洗 → DI 水 → 烘乾
```

### 鈍化適用 / 不適用

```
適用                          不適用 (或需特殊處理)
─────────────────────────────────────────────────
SUS304 / 316 / 316L           SUS400 系 (馬氏體) — 改鈍化液
SUS17-4PH / 15-5PH            Cu / Ni 含量 > 5% → 用 Method 5
SUS430 (鐵素體)                鉻含量 < 11% → 不是不銹鋼
焊縫 + 母材一起鈍化            焊接彩色未先酸洗
精密件                         > 5h 鈍化會過蝕
```

### 電解拋光 (Electropolishing, EP)

```
液:    H2SO4 + H3PO4 + 添加劑
條件:  60-80°C, 5-15 V DC, 5-30 min, 陰極不銹/鉛
效果:  Ra 0.4 → 0.1 µm
       去毛刺、去夾雜、富鉻表層 Cr/Fe 比從 1:2 → 1:1
應用:  食品 (CIP)、半導體腔、生醫植入物、醫療器械、製藥
規範:  ASTM E1558, ASME BPE
```

### 焊接彩色 (Heat Tint) 處理

```
彩色等級    描述               處理
────────────────────────────────────────
1-2 級     淡黃 / 麥色         鈍化即可
3-4 級     深金 / 紅紫         酸洗 + 鈍化
5-6 級     深藍 / 黑藍         機械研磨 + 酸洗 + 鈍化
7-10 級    黑灰 / 結晶         研磨除盡 → 全槽酸洗 → 鈍化
依據: AWS D18.2 (彩色比色卡)
```

### 鈍化驗證測試

| 測試 | 規範 | 判定 |
|---|---|---|
| **硫酸銅試驗** (CuSO4 dip) | ASTM A967 Practice B | 6 min 內無銅色析出 → OK |
| **濕度試驗** | ASTM A380 | 24h 5°C 凝露 後無銹斑 |
| **鹽霧** | ASTM B117 | 食品 / 醫療: 24-48h 無銹 |
| **鐵氰化鉀檢測** | — | 無藍色斑 → 無游離鐵 |
| **電化學** (ASTM G150) | 點蝕電位 Epit 上升 ~100mV | EP 後典型 |

### Ra 對應應用

```
Ra (µm)   應用
─────────────────────────────────
> 1.6     工業件、結構
0.8       裝飾、一般食品
0.4       食品 GMP / 飲料
0.2       製藥 BPE (Bio-Pharm)
< 0.1     半導體 (高純氣體管)、UHV
```
