## 淬火 + 回火 (Quench & Temper)

### 淬火介質選擇

| 介質 | 冷速 | 適用 | 變形/裂紋風險 |
|---|---|---|---|
| 水 | 最快 | 低碳鋼 / 低淬透性 | 高 |
| 鹽水 (5-10% NaCl) | 比水更快 | 低淬透性、薄件 | 很高 |
| 油 | 中 | 多數合金鋼 SCM / SNCM / SCr | 中 |
| 等溫淬火油 / 鹽浴 | 慢 + 等溫 | SKD / SKH 高合金 | 低 |
| 真空 / 氣淬 (N2/He 高壓) | 可控 | 模具鋼 SKD11/SKD61 / 不銹鋼 | 最低 |
| 空冷 | 最慢 | 高合金 (SKD11 air-hard) | 低 |

### 回火脆性帶 (Temper Embrittlement) — 必須避開

- **第一類回火脆性** 250-400°C — 幾乎所有合金鋼 → 該區回火後韌性掉
- **第二類回火脆性** 450-650°C 緩冷 — SCM/SNCM 含 Cr-Ni 鋼 → 從高溫回火後要快冷
- **應對**: 1) 避開該溫度區間; 2) 該區若必需通過, 加入 Mo (0.3-0.5%) 抑制; 3) 高溫回火後油冷或水冷

### 淬火裂紋常見原因

```
原因                         對策
─────────────────────────────────────────────────────
冷速太快 (水淬高碳鋼)         改油淬 / 等溫淬火
形狀有尖角 / 截面突變          設計時加 R 角、避免厚薄懸殊
表面脫碳                       保護氣氛 / 預塗硼砂 / 真空爐
未及時回火 (放隔夜開裂)        出爐立刻回火 (最遲 4h 內)
奧氏體化溫度過高               對照鋼種規範,寧低勿高
含氫量高 (酸洗後直接淬)        先去氫退火
```

### 變形控制

- 對稱加工、對稱裝爐
- 預先去應力 (560°C × 2h)
- 用夾具 / 模具夾持淬火
- 真空爐 + 高壓氣淬 對精密模具最友善
- 預留磨削裕量: 一般 0.2-0.5mm / 邊
