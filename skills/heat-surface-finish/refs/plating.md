## 電鍍 / 化學鍍 (Plating)

### 主流製程速查

|---|---|---|---|---|---|---|
| **鍍鋅 (Zn)** | 5-25µm | HV ~50 | 銀白/藍白/黃/黑/彩 (依鈍化) | 96-720h | 扣件、結構件防銹 (一般環境) | ASTM B633 / ISO 4042 |
| **熱浸鍍鋅 (HDG)** | 45-150µm | — | 銀灰、結晶 | > 1000h | 戶外鋼結構、護欄 | ASTM A123 |

## 鍍鋅後鈍化選擇

- **藍白 / 銀白** (三價鉻) — 外觀好、耐鹽霧 96-120h
- **彩鋅 / 黃鋅** (三價鉻或六價) — 耐鹽霧 192-240h, 六價已禁用 (ROHS / ELV / REACH)
- **黑鋅** — 耐鹽霧 96-240h, 外觀黑
- **軍綠** — 耐鹽霧 > 240h, 軍工件
- **封閉劑** (Sealer / Top Coat) — 可再 +200-500h 鹽霧

## 氫脆控制 (Hydrogen Embrittlement)

```
HRC > 32 工件鍍鋅/鎘 → 必須去氫退火
參數: 190-220°C × 8-24h
時機: 鍍後 4 小時內進爐
等級: ASTM F519, ISO 9588
驗證: 缺口拉伸試片 200h 不斷
```

## 化學鎳 (Ni-P) 含磷量選擇

| 含磷 | 性質 | 應用 |
|---|---|---|
| 低磷 (1-3% P) | 硬度高 (HV 700)、磁性、耐磨 | 模具、刀具 |
| 中磷 (5-9% P) | 平衡耐磨耐蝕 | 通用 (最常見) |
| 高磷 (10-13% P) | 耐強酸耐強鹼、非磁、HV 500 | 化工、油氣、PCB |

## 鍍層常見缺陷

```
缺陷         原因                                  對策
──────────────────────────────────────────────────────────────────
起泡         基材含油 / 鍍前清洗不足 / 氫過量       強化前處理、去氫退火
針孔         鍍液污染 / 攪拌不足 / 添加劑失衡        過濾活性炭、補添加劑
燒焦發黑     電流密度過大、邊緣尖端                  降電流、加導電輔助
鍍層粗糙     鍍液有顆粒、陽極泥                      過濾、清陽極
剝離         前處理活化不足、不同金屬無中間層        加 Cu / Ni 中間層
色差         電流分佈不均、添加劑分層                改善掛具、加輔助陰極
白霧         (鍍鋅) 鈍化後曝露空氣中水分             封閉劑、控制濕度
彩虹紋       鍍鎳厚度不均 / 拋光不均                 改善底材拋光
```

## 鍍前必做

1. **除油** (鹼洗 60-70°C)
2. **酸洗 / 酸活化** (HCl 5-10%)
3. **電解除油** (碳鋼: 陰極 → 陽極切換, 不銹鋼: 陽極)
4. **水洗 × 3**
5. **預鍍 (Strike)** — 不銹鋼 / 鋅合金壓鑄: Wood's Ni / 氰化銅
6. **正鍍**
