## 噴漆 / 粉體塗裝 / 電泳 / 噴砂

### 漆膜製程比較

| 製程 | 膜厚 | 耐候 | 顏色彈性 | 設備 | 適用量 |
|---|---|---|---|---|---|
| **濕式噴漆** (溶劑 / 水性) | 20-100µm | 中 | 極多 | 噴槍 + 烤箱 | 小量 / 多色 / 補漆 |
| **粉體塗裝** (Powder Coat) | 60-150µm | 高 | 多 (限 RAL/PMS) | 靜電槍 + 180-200°C 烤爐 | 中大量 / 一致性 |
| **電泳 (E-Coat)** | 15-30µm 底漆 | 高 (打底用) | 黑/灰為主 | 槽鍍 + 烤爐 | 大量 / 全鍍 (汽車車體) |
| **氟碳塗料** (PVDF) | 30-60µm | 極高 (20-30 年) | 多 (Kynar 500) | 噴漆 + 250°C 烤 | 建築幕牆、戶外鋁件 |
| **UV 塗料** | 5-30µm | 中 | 多 | UV 燈固化 | 3C 表面、塑膠 |

### 粉體塗裝詳細參數

```
1. 前處理 (Zn 磷化 / Zr 鈍化)
   除油 → 除銹 → 表調 → 磷化 / Zr 鈍化 → 水洗 → DI 水
2. 烘乾 120-140°C
3. 靜電上粉 (60-90 kV)
4. 固化 180-200°C × 15-20 min (依粉系)
   - 環氧 (Epoxy)       160-180°C — 室內,耐化最佳
   - 環氧聚酯 (Hybrid)   180°C — 室內,平衡
   - 聚酯 (Polyester)   200°C — 戶外,耐 UV
   - 聚氨酯 (PU)        180-200°C — 戶外,豐滿光
   - 氟碳 (PVDF)        230-250°C — 建築,20 年戶外
5. QC: 膜厚 ASTM D7091, 附著 ASTM D3359 (劃格 0-5級), 耐衝擊 ASTM D2794
```

### 漆膜常見缺陷

```
缺陷         原因                                 對策
─────────────────────────────────────────────────────────────
橘皮         噴距遠 / 黏度高 / 烤溫高              縮距、稀釋、降溫
流掛         一次噴太厚 / 黏度低                   多薄塗、提高黏度
針孔         前處理油 / 氣泡未消                   強化除油、慢升溫
縮孔 (魚眼)  矽油污染 (空壓含油)                   過濾空壓、防矽油
顆粒 (麻面)  粉塵 / 槍嘴髒                         潔淨室、清槍
色差         批次差 / 烤溫不均                     同批使用、爐溫繪圖
附著差       前處理弱 / 鈍化失效                   重做前處理
粉化 (戶外)  UV 老化 / 用了室內粉                  改聚酯 / 氟碳
```

### 噴砂 (Blasting) — 鍍/塗前處理

| 砂類 | 用途 | 表面狀態 |
|---|---|---|
| 鋼砂 / 鋼丸 (Steel grit / shot) | 重型除銹、噴丸強化 | 粗、Ra 5-15µm |
| 氧化鋁 (Al2O3) | 通用、鋁件 | 中、Ra 1-5µm,銳角 |
| 玻璃珠 (Glass bead) | 霧面、不銹鋼修飾 | 細、Ra 0.5-2µm,圓滑 |
| 矽砂 (Silica) | 通用 (含 SiO2,有矽肺風險,已少用) | 中 |
| 碳化矽 (SiC) | 不銹/工具鋼 | 銳、清潔度最高 |
| 塑膠砂 (Plastic) | 鋁件去毛刺、不可損傷 | 細 |
| 乾冰 (CO2 dry ice) | 模具清洗,無研磨 | 無材損 |
| 核桃殼 | 木質 / 機殼除漆 | 軟 |

### 噴丸強化 (Shot Peening) — 提升疲勞壽命

- 鋼丸 / 玻璃丸 / 陶瓷丸高速衝擊 → 表層殘餘壓應力
- Almen 試片強度: A2 / A4 (彈簧鋼常見)
- 覆蓋率 ≥ 98%
- 疲勞壽命提升: 20-200%
- 規範: AMS 2430 / SAE J442

### 表面處理組合常見方案

```
要求                              組合
────────────────────────────────────────────────────────
廉價防銹 + 外觀                    噴砂 → 鍍鋅 → 三價鉻彩鈍 → 封閉
戶外建築鋁件 20 年                 陽極 (Type II) 或 PVDF 粉塗
汽車車身                           磷化 → 電泳底漆 → 中塗 → 面漆
食品設備                           電解拋光 + 鈍化
模具壽命                           氮化 + PVD AlCrN
傳動軸耐磨                         滲碳淬火 + 噴丸 + 化學鎳
活塞桿                             調質 + 感應淬火 + 鍍硬鉻 + 拋光
```
