## PVD / CVD / DLC 塗層 (Coatings)

### 主流刀具/模具塗層

| 塗層 | 顏色 | 硬度 HV | 摩擦係數 | 最高溫 | 主用 |
|---|---|---|---|---|---|
| **TiN** (氮化鈦) | 金 | 2300 | 0.55 | 600°C | 通用刀、模具,基本款 |
| **TiCN** (碳氮化鈦) | 紫紅 / 灰 | 3000 | 0.40 | 400°C | 高強度切削、攻牙 |
| **TiAlN / AlTiN** | 黑紫 / 紫黑 | 3300-3500 | 0.40 | 900°C | 高速切削、乾切、HRC60+ 加工 |
| **AlCrN** | 灰藍 | 3500 | 0.35 | 1100°C | 高溫合金、不銹鋼粗加工 |
| **TiSiN** | 銅 | 3500-4000 | 0.45 | 1100°C | 超硬切削、刀模耐磨 |
| **CrN** | 銀灰 | 1800 | 0.50 | 700°C | 鋁加工 (不黏鋁)、塑膠模 |
| **DLC** (a-C:H) | 黑 | 2000-4000 | 0.05-0.20 | 350°C | 低摩擦、汽機車零件、3C |
| **ta-C** (四面非晶碳) | 黑 | 5000-8000 | 0.10 | 500°C | 極致耐磨、生醫 |
| **CBN (PCBN)** | 棕 | 4500 | — | 1300°C | 加工 HRC60+ 淬火鋼 |
| **多層 (Multilayer)** | 視組合 | 自訂 | 自訂 | 自訂 | 客製化 (如 TiN/AlTiN 交替) |

### PVD vs CVD

```
            PVD (物理氣相沉積)         CVD (化學氣相沉積)
──────────────────────────────────────────────────────────
溫度       200-500°C (低)             800-1100°C (高)
變形       極小                       明顯 (要熱處理後)
基材       高速鋼 / 工具鋼 / 不銹 OK   只能高溫穩定材
膜厚       1-5 µm                     5-20 µm
附著       中-好                      佳 (擴散接合)
方向性     有 (掛具要轉)               全方位均勻 (反應氣體環繞)
殘餘應力   壓應力 (好,抗裂)          拉應力 (差)
主流用    刀具、精密模具、3C 件       切削嵌入式刀片 (碳化鎢)
典型製程  Sputter / Arc / HiPIMS    熱 CVD / PACVD / 中溫 MTCVD
```

### 應用選擇邏輯

```
切削對象                推薦
─────────────────────────────────────
鋁 / 銅 / 黏材           DLC / CrN / 無塗層
碳鋼 / 合金鋼            TiN / TiCN
不銹鋼                   TiAlN / AlCrN
高溫合金 (Inconel)       AlCrN / TiSiN
鈦合金                   AlCrN / DLC
HRC 55+ 淬火鋼           AlTiN / AlCrN / CBN
複合材料 (CFRP)          DLC / 鑽石塗層
冷沖模具                 TiCN / TiAlN
熱間鍛模                 AlTiN / AlCrN
塑膠射出模 (光學)        DLC / CrN
食品/醫療接觸            DLC (生物相容)
```

### 塗層前置條件

```
1. 基材硬度  必須 ≥ HRC 58 (否則塗層失支撐)
2. 表面粗糙度 Ra ≤ 0.4 (越光越好)
3. 銳邊處理  R 0.02-0.05 (避免應力集中導致剝離)
4. 清潔     超音波 + 等離子預處理 (去除有機 + 氧化)
5. 去磁     磁性件鍍前去磁
6. 模具孔洞  深盲孔內塗層差 → 直徑 < 5 倍深可
7. 變形容許  PVD 變形 < 5 µm,但 200-500°C 仍有 1-2 µm 漲縮
```

### 剝離常見原因

- 基材軟 (HRC < 55)
- 拋光不到位 → 殘留刀痕
- 油 / 指紋 / 切削液殘留
- 角度太銳 (< R0.05)
- PVD 槽真空度不足 → 含水 → 氧化界面
- 塗層過厚 (> 5µm) → 內應力剝
- 工件存放於高濕 / 鹽霧環境 (鍍前)

### 規範

- ISO 27307 — Thermal spray coating
- VDI 3198 — Rockwell C 塗層附著測試 (HF1-HF6)
- ASTM C1624 — Scratch test (划痕)
- DIN EN 1071-3 — Calotest (磨穿深度測膜厚)
