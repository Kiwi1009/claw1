## 製程地圖 — 從圖紙反查該用什麼

```
客戶要求                          → 製程選擇
─────────────────────────────────────────────────────────────
HRC 55-65 整體硬                  → 淬火 + 低溫回火 (高碳鋼/工具鋼)
HRC 28-35 韌性 + 強度              → 調質 (淬火 + 高溫回火) — 中碳鋼最常見
HRC 50-62 表面硬 / 心部韌          → 滲碳 (低碳鋼) / 氮化 (合金鋼) / 感應淬火
HV 800-1200 高耐磨表層 (薄)        → 氮化 / PVD TiN/AlTiN / DLC
無變形 + 表面硬                    → 氮化 (520°C 不淬火) / 感應淬火 (局部)
防銹 (一般環境)                    → 鍍鋅 + 三價鉻鈍化 (ROHS 後主流)
防銹 (海邊 / 化工)                 → 不銹鋼鈍化 / 電解拋光 / 化學鍍鎳
防銹 (高溫)                        → 達克羅 (Dacromet) / 滲鋁
鋁件外觀 + 耐磨                    → 陽極處理 Type II (5-25µm) + 封孔
鋁件硬陽極 (硬度 HV400+)           → 陽極處理 Type III (25-100µm)
鋁件防腐輕量                       → 陽極處理 Type I (CAA, 鉻酸陽極, 薄)
裝飾性高光                         → 鍍鎳 + 鍍鉻 (六價或三價)
食品 / 醫療接觸                    → SUS 鈍化 / 電解拋光 (Ra < 0.4)
刀具 / 模具壽命                    → PVD TiN / TiCN / AlTiN / DLC / CrN
塑膠模具 (蝕紋耐磨)                → 氮化 + 拋光 / 鍍硬鉻 / PVD CrN
精密齒輪 / 軸承                    → 滲碳淬火 + 表面磨削 + 噴丸
冷沖模具                           → SKD11 / DC53 真空淬火 → HRC 60-62
熱間鍛模                           → SKD61 真空淬火 → HRC 48-52 + 氮化
```

## 製程選擇思考順序

1. **基材是什麼?** — 碳鋼 / 合金鋼 / 不銹鋼 / 鑄鐵 / 鋁 / 銅 / 鈦?
2. **要的是什麼?** — 整體強度 / 表面硬 / 防銹 / 外觀 / 導電?
3. **變形容許多少?** — 淬火變形 vs. 氮化幾乎無變形
4. **環境如何?** — 內陸 / 海邊 / 高溫 / 化工
5. **量大量小?** — 鹽浴 / 真空 / 連續爐 / 局部感應
6. **後續加工?** — 熱處理後還要不要研磨? 鍍前要不要除應力?
7. **預算 vs. 壽命** — 鍍硬鉻便宜但慢退, PVD 貴但長命
