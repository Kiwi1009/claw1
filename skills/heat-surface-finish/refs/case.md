## 表面硬化 (Case Hardening)

| 製程 | 溫度 | 時間/深度 | 表面硬度 | 變形 | 適用 |
|---|---|---|---|---|---|
| **滲碳 (Carburizing)** | 920-950°C 滲碳 + 淬火回火 | 0.3-2mm (4-20h) | HRC 58-62 | 中 (需淬火) | 齒輪、凸輪、軸承座 (低碳鋼 / 滲碳鋼 SCM415/SCM420) |
| **氮化 (Gas Nitriding)** | 500-560°C × 20-100h | 0.1-0.6mm | HV 900-1200 (~HRC 65-70) | 極低 (不淬火) | 模具、活塞、曲軸、精密軸 (SACM645 / SCM440 / 38CrMoAl) |
| **氮碳共滲 (Tufftride/QPQ)** | 560-580°C × 1-4h | 10-30µm | HV 600-1100 | 極低 | 防咬死、防銹耐磨組合需求 |
| **離子氮化 (Plasma Nitriding)** | 480-580°C × 10-50h | 0.05-0.5mm | HV 900-1300 | 極低 | 不銹鋼、模具 (可控化合物層) |
| **感應淬火 (Induction)** | 局部 850-1050°C | 1-8mm | HRC 50-60 | 低 (局部) | 軸頸、齒輪節圓、導軌 (中碳鋼 S45C/S50C 為主) |
| **火焰淬火 (Flame)** | 局部 ~900°C | 1-10mm | HRC 50-58 | 低 | 大型工件局部 (滾輪、導軌) |
| **激光淬火 (Laser)** | 局部 1000-1500°C | 0.1-1.5mm | HRC 55-62 | 極低 | 精密件局部、複雜形狀 |
| **滲硼 (Boronizing)** | 850-1000°C × 4-10h | 30-200µm | HV 1500-2100 | 中 | 極端耐磨 (擠出螺桿、礦山件) |
| **滲鋁 (Aluminizing)** | 700-1000°C | 30-200µm | — (高溫抗氧化) | 中 | 燃氣輪機葉片、加熱爐元件 |

## 滲碳製程詳解

```
1. 預熱      400-600°C × 1-2h (避免熱衝擊)
2. 滲碳      900-950°C, 滲碳氣氛 (CP 0.8-1.2%), 時間 = (深度mm)^2 × 5h
3. 擴散      900-920°C, CP 0.6-0.8% (讓碳濃度梯度平緩)
4. 降溫等溫  830-850°C × 0.5h (準備淬火)
5. 直接淬火  油淬 → HRC 58-62
6. 低溫回火  150-180°C × 2h
7. 噴丸     可選, 提升疲勞壽命 20-50%
```

## 氮化前提條件

- **必須先調質** (淬火 + 高溫回火) → 心部 HRC 28-35 給氮化層支撐
- **氮化前精加工** 留 0.02-0.05mm 磨削裕量即可 (氮化幾乎無變形)
- **不能磨太多** — 氮化層 0.1-0.5mm, 磨穿就沒了
- **不適合**: 純碳鋼 (沒 Cr/Al/Mo 等氮化物形成元素) → 用 SACM645 (38CrMoAl) / SKD61 / SKH51 / SUS420 等

## 感應淬火 — 模塊化參數

```
頻率選擇 (硬化層深度反比於頻率)
─────────────────────────────────
高頻 (100-500 kHz)  深度 0.5-2mm   小齒輪、軸頸
中頻 (1-10 kHz)     深度 2-5mm     中型齒輪、曲軸
工頻 (50 Hz)        深度 > 8mm     大軸、軋輥
```

## 不同要求 → 對應製程

```
要求                         推薦
─────────────────────────────────────────
精密件 0 變形 + 表硬 HRC 60   氮化 / 離子氮化
量產齒輪 HRC 60 + 心韌        滲碳淬火
單一截面硬化 (軸頸/節圓)      感應淬火
小批量 + 複雜形狀             激光淬火
不銹鋼要硬                    離子氮化 (S 氮化 不破壞耐蝕性)
要硬還要外觀                  QPQ (氮碳共滲 + 氧化)
```
