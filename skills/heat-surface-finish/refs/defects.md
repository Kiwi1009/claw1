## 常見缺陷對應表 (Defects Catalog)

### 熱處理類

| 缺陷 | 表徵 | 原因 | 對策 |
|---|---|---|---|
| 淬火裂 (Quench Crack) | 出爐後 / 隔夜開裂 | 冷速過快、形狀尖角、未及時回火 | 改油 / 等溫淬火、加 R 角、出爐 4h 內回火 |
| 軟點 (Soft Spot) | 局部硬度低 | 介質汽化膜 / 接觸不勻 | 攪拌、加速冷卻劑、面朝下 |
| 脫碳 (Decarburization) | 表面硬度低於心部 | 爐氣氧化、加熱過長 | 保護氣氛 / 真空、控制時間 |
| 增碳 (Carburization) | 不希望卻意外滲碳 | 爐氣 CP 過高、油霧污染 | 換爐子 / 換氣氛 |
| 過熱 (Overheating) | 晶粒粗大 → 韌性差 | 加熱溫度過高 | 重新正火 → 再淬火 |
| 過燒 (Burning) | 晶界氧化 → 報廢 | 嚴重過熱 | 無法挽救 |
| 變形 (Distortion) | 尺寸超差 / 翹曲 | 不對稱、冷速不均、未預應力消除 | 對稱裝爐、夾具、預應力退火 |
| 回火脆性 (Temper Embrittlement) | 回火後韌性反降 | 在 250-400 / 450-650°C 慢冷 | 避開該區、含 Mo、回火後快冷 |
| 白層 (White Layer) | 表面顯微鏡白色硬化層 | EDM 火花後、感應淬火過熱 | EDM 後磨除 0.05-0.1mm |
| 滲碳異常層 | 黑色網狀 / 殘餘奧氏體過多 | 滲碳氣氛失控、淬火介質溫度高 | 補做冷處理 (-80°C) + 重新回火 |

### 鍍層 / 表面處理類

| 缺陷 | 表徵 | 原因 | 對策 |
|---|---|---|---|
| 起泡 (Blistering) | 凸起、剝離 | 基材含油 / 含氫 | 強化除油、去氫退火、改善預鍍 |
| 針孔 (Pinholes) | 微小孔點 | 槽液污染、攪拌差 | 過濾、活性炭、加添加劑 |
| 麻點 (Pitting) | 蝕坑點 | Cl⁻ 污染、有機污染 | 換槽、隔離 |
| 燒焦 (Burning) | 邊緣發黑 | 電流密度過大 | 降電流、輔助陰極 |
| 剝離 (Peeling) | 整片脫落 | 前處理活化不足 / 中間層 | 加 Strike (Wood's Ni), 確認酸活化 |
| 白霧 (White Fog / 白銹) | (鍍鋅後) 白色斑 | 鈍化不足 / 受潮 | 補鈍化 / 封閉劑 |
| 色差 (Color Variation) | 同批不一 | 電流分佈不均 / 槽液成分變動 | 改善掛具、頻繁分析 |
| 鍍層薄 / 不均 | 厚度不到 | 電流不夠 / 時間短 / 接觸不良 | 校儀器、量厚抽檢 |
| 氫脆 (Hydrogen Embrittlement) | 受負載突然斷裂 | HRC > 32 鍍鋅未去氫 | 鍍後 4h 內 190°C × 8-24h 烘烤 |

### 陽極 / 鈍化類

| 缺陷 | 表徵 | 原因 | 對策 |
|---|---|---|---|
| 染色斑 (Dye Mottle) | 染色不均 | 染前水洗不足 / 染料 pH | 充分水洗、控 pH |
| 封孔斑 (Sealing Bloom) | 灰白霜 / 粉感 | 封孔水質差 / 染料未洗淨 | DI 水、染後充分洗 |
| 龜裂 (Crazing) | 細紋網狀 | 硬陽極升壓快 / 截面厚薄差 | 緩升、預熱、修圓角 |
| 色差 (鋁陽極) | 同件深淺 | 槽溫不均、攪拌差 | 加循環、控 ±1°C |
| 鈍化失效 (CuSO4 變色) | Cu Test 銅析 | 鈍化時間不夠、酸度錯 | 重做鈍化、檢液 |
| 焊縫彩色未除 | 焊縫附近耐蝕差 | 酸洗不足 | 加長酸洗 / 機械研磨 |

### 塗裝類

| 缺陷 | 表徵 | 原因 | 對策 |
|---|---|---|---|
| 橘皮 (Orange Peel) | 像橘子皮紋 | 黏度高 / 噴距遠 / 烤溫高 | 稀釋、近噴、降溫 |
| 流掛 (Sagging) | 漆膜下垂 | 一次噴太厚 | 多薄塗 |
| 縮孔 / 魚眼 (Fish Eye) | 圓形凹點 | 矽油污染 | 過濾空壓、防矽油 |
| 顆粒 (Seeds) | 砂感 | 環境粉塵 / 槍嘴髒 | 潔淨室、清槍 |
| 附著差 (Poor Adhesion) | 劃格脫落 | 前處理弱 | 重做磷化 / 鈍化 |
| 粉化 (Chalking) | 戶外發白起粉 | UV 老化 / 室內粉戶外用 | 改聚酯 / 氟碳 |

## 缺陷排查 SOP

```
1. 確認缺陷位置 + 模式 (整批 / 個別 / 局部)
2. 反追製程: 取上一站試片驗
3. 試片切片 + 顯微 (金相 / SEM)
4. 槽液 / 爐氣分析 (Cl⁻ / Cr⁶⁺ / CP / 雜質)
5. 對照規範: ASTM B117 鹽霧 / ASTM D3359 附著 / ASTM E384 硬度
6. 重做試片驗證對策
7. 文件: 8D 報告 + CAPA
```
