## 退火 / 正火 / 應力消除

| 製程 | 溫度範圍 | 冷卻 | 目的 | 適用 |
|---|---|---|---|---|
| **完全退火** (Full Annealing) | Ac3 + 30-50°C (碳鋼 ~860°C) | 爐冷 < 30°C/h | 軟化、改善切削性、消除組織不均 | 鍛件、鑄件、軋件 |
| **球化退火** (Spheroidizing) | Ac1 ± 20°C (~720-760°C) | 緩冷 / 等溫 | 把片狀滲碳體球化 → 易切削 + 易冷拔 | 高碳鋼、工具鋼 SKD11 / SKS / SK |
| **正火** (Normalizing) | Ac3 + 30-80°C | 空冷 | 細化晶粒、消除帶狀組織、HB 提升 | 中低碳鋼鍛件、焊後處理 |
| **應力消除退火** | 500-650°C (亞臨界) | 爐冷 / 空冷 | 消除機加 / 焊接 / 冷加工殘留應力 | 焊接結構、精密件粗加工後 |
| **去氫退火** | 180-220°C × 4-24h | 空冷 | 消除電鍍 / 酸洗滲入的氫 → 防氫脆 | 高強度鋼鍍後 (HRC > 32 必做) |
| **再結晶退火** | 0.4 × Tm 附近 | 空冷 | 冷加工後恢復塑性 | 冷軋板 / 冷拔線 |

## 常見鋼種退火範例

```
S45C   完全退火: 840°C × 2h → 爐冷 720°C → 空冷    硬度: HB 160-200
SCM440 完全退火: 830°C × 2h → 爐冷 600°C → 空冷    硬度: HB 200-240
SKD11  球化退火: 760°C × 4h → 等溫 700°C × 6h     硬度: HB ≤ 255
SKD61  完全退火: 860°C × 3h → 爐冷                 硬度: HB ≤ 229
SUS440C 球化退火: 870°C → 等溫 685°C × 6h          硬度: HB ≤ 285
```

## 注意

- **爐冷速度** 是關鍵 — 用退火爐 (帶風扇) 比箱爐均勻
- **保溫時間** 經驗值: 截面 25mm 約 1h
- **保護氣氛** 不銹鋼/工具鋼用氮氣或真空 → 防脫碳、防氧化皮
- **去氫退火必做時機**: 鍍鋅 / 鍍鎘 / 酸洗後 + 工件 HRC > 32 + 4 小時內進爐
